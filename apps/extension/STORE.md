# Chrome ウェブストアへ出すときの文面

ストアの入力欄へ、そのまま貼る文面です。**拡張の動きを変えたら、ここも同じ commit で直します**
（とくに「データの扱い」。動きと申告がずれると、審査で落ちるか、利用者に嘘をつくことになります）。

## 出すもの

```
pnpm --filter @mmj-map/extension pack:store
```

`apps/extension/mmj-extension-<版>.zip` ができます。版は `src/manifest.json` と `package.json` で
同じにしてあり、試験で突き合わせています。**ストアに 2 回目を出すときは、両方の版を上げます。**

## 掲載情報

**名前**（manifest から自動）: MMJ — 開いている地図を、自分の頁の地図に

**概要**（manifest から自動・132 字以内）:
地図の頁で押すと、同じ場所を API キーなしで置ける HTML を出します。AI に渡す形でも写せます。読むのはタブの URL だけです。

**カテゴリ**: デベロッパー ツール

**言語**: 日本語

**説明**:

```
Google マップで開いている場所を、自分のサイトに置ける地図にします。

・API キーも、地図のサーバーも要りません。地図は 1 ファイル（PMTiles）とスタイルを静的に置くだけで動きます
・会社名・店名、住所、ホームページを入れると、吹き出し付きのピンが立ちます
・携帯と PC の幅、明るい地図と暗い地図で、頁に置いたときの見え方を確かめられます
・「HTML を写す」で、そのまま貼れる HTML を出します
・「AI に渡す形で写す」で、手順と守ることを添えた文面を出します。サイトを作っている AI にそのまま渡せます

読むのは、押したときに開いているタブの URL（地図の中心と縮尺）だけです。
店名や地点など、地図サービスの中身は読みません。入れた名前や住所は、どこにも送りません。

地図のデータは OpenStreetMap（© OpenStreetMap contributors, ODbL）です。
ソース: https://github.com/meta-taro/mmj-map
```

**スクリーンショット**（1280×800）:

1. 見本の頁・PC 幅・明るい地図（名前・住所・ホームページを入れた吹き出し）
2. 見本の頁・携帯幅・暗い地図

撮るときは**作り物の名前と住所**を入れます（実在の会社を写さない）。

## プライバシー

**単一用途**:

```
開いている地図の表示位置（中心と縮尺）から、自分のサイトに置ける地図の HTML を作ること。
```

**activeTab の理由**:

```
拡張のボタンを押したときだけ、そのタブの URL から地図の中心と縮尺を読むためです。
頁の中身は読まず、頁にスクリプトも入れません。ほかのサイトを読む権限は持っていません。
```

**リモートコード**: 使っていません。

```
MapLibre・pmtiles・部品はすべて拡張の中に入れています。外から読むのは、見本に使う地図のタイルと
スタイル（JSON）だけで、どちらもデータです（https://meta-taro.github.io/mmj-map/）。
```

> **拡張が実行しない文字列も審査される**。0.1.0 は「貼る HTML」の文面に入っていた
> pmtiles の CDN の `<script src>` を理由に、Blue Argon（MV3 のリモートコード）で拒否された（2026-11-05）。
> 0.1.1 から、貼る HTML は MapLibre と pmtiles を頁の隣（`./vendor/`）から読む。
> `test/package.test.js` が実際に `dist/` を組み、出すファイルに外からコードを読む書き方が無いことを見る。

**データの使用**: 何も集めていません（どの項目にも印を付けない）。

- 入れた名前・住所・ホームページは、その頁の中だけで使います。保存も送信もしません
- 見本の地図を出すとき、表示している範囲のタイルを上の公開先から読みます。
  公開先は GitHub Pages で、こちらはそのログを見ていません

開示の 3 項目（承認された用途以外で販売・転送しない／単一用途に関係ない目的で使わない／
信用力の判断に使わない）には、すべて同意します。

**プライバシー ポリシーの URL**: 集めるデータが無いので必須ではありません。求められたら
`https://github.com/meta-taro/mmj-map/blob/develop/apps/extension/STORE.md#プライバシー` を入れます。
