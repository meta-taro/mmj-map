素の MapLibre で描く

手書きのスタイル（styles/modern-dark.json）と PMTiles だけで描いています。 地図サーバーは立てていません。

はじめに 素の地図 HTML だけで置く 建物を立てる 点をまとめる 自前の POI 経路と案内 配色を見くらべる サイトの色を当てる 地域を切り替える リポジトリ

まだタイルの配信元がありません

このデモは、ベースタイル（PMTiles）とグリフの配信元が決まると地図を描きます。 配信元は apps/demo/config.js に設定します。

自分でタイルをビルドして配信する手順は、リポジトリの README を見てください。

空の地図を出す代わりに、この案内を出しています。 無いものを、あるように見せないためです。
