地図へ飛ぶ

React から使う

この頁でできること

@mmj-map/react の <MmjMap> と <MmjMarker> を、 React の state から描いています。「店を足す」「最後の店を消す」で目印が増え減りします。 「線を引く」を押すと <MmjRouteEditor> が出て、引いた結果を onMmjRouteChange で受け取り、下の行に出します。 地図の本体は Web Components のままで、React 側は名前の書き換えと受け渡しだけです。

はじめに 素の地図 HTML だけで置く React から使う 建物を立てる 点をまとめる 自前の POI お店を見て回る 経路と案内 線だけで道案内 3D で道案内 配色を見くらべる サイトの色を当てる 地域を切り替える 会場の地図 半径で囲む 重ねる 雨雲を動かす 面で塗り分ける リポジトリ

まだタイルの配信元がありません。apps/demo/config.js に設定します。
