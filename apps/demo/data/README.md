# デモ用のデータ

## `sample-points.geojson`（200 点）

`<mmj-cluster>` が点をまとめる様子を確かめるためのデータです。

**実在の施設・店舗・イベントではありません。**梅田 / 難波 / 大阪城 / 堺 の 4 か所を
中心に、seed を固定した疑似乱数で散らしただけの合成点です。

実在のデータに見えるものを作り置くと、**いつか誰かがそれを本物として使います**。
`properties.name` を「サンプル点 N」にしてあるのはそのためです。

生成に使った値は次の通りで、同じ手順から同じファイルが出ます。

| 中心 | 経度 / 緯度 | 点数 | 散らす幅（度） |
|---|---|---|---|
| 梅田 | 135.4959 / 34.7024 | 70 | ±0.012 |
| 難波 | 135.5022 / 34.6659 | 60 | ±0.010 |
| 大阪城 | 135.5258 / 34.6873 | 40 | ±0.008 |
| 堺 | 135.4830 / 34.5733 | 30 | ±0.020 |

- 乱数は線形合同法（`s = (s * 1103515245 + 12345) % 2147483648`）、seed は `20260917`
- 緯度側だけ幅を 0.8 倍している（この緯度では経度 1 度のほうが短く、
  等倍にすると縦長の固まりに見えるため）
- 座標は小数 5 桁（約 1m）で丸めている

## `own-poi.geojson`（8 点）

`<mmj-poi>` が**利用者の持ち込みデータ**を重ねる様子を確かめるためのものです。

**実在の店舗ではありません。**京セラドーム周辺（135.4761 / 34.6693）に、
seed `20260917002` の同じ線形合同法で 8 点散らしただけの合成点です。

**名前は `name` ではなく `shop_name` に入れてあります。**
媒体ごとに属性名が違うこと（`label-key` で指定できること）を、
デモ側でも実際に使って示すためです。

## `sample-route.geojson`（経路 1 本 ＋ 案内 3 点）

`<mmj-route>` が経路を描き、曲がる地点に吹き出しを置く様子を確かめるためのデータです。

**線はタイルの中の実際の道路の座標です。**最初の版は手で書いた折れ線で、
**道を無視して建物と川を突っ切っていました**（2026-09-21・人の指摘
「道を無視して、線がひかれているのがきになります」）。
地図の上に乗らない線を置くと、**部品が正しくても画面が嘘になります。**

座標は配っているタイルから取り出したもので、同じ手順で再現できます。

```bash
pnpm tile:inspect -- dist/tiles/demo.pmtiles 15 28717 13012 --layer=roads --geo --name=御堂筋
pnpm tile:inspect -- dist/tiles/demo.pmtiles 15 28717 13013 --layer=roads --geo --name=曽根崎通
```

| | |
| --- | --- |
| 通っている道 | 御堂筋（南へ）→ 曽根崎通（東へ） |
| 距離 | 約 896 m / 18 点 |
| 出発 | 大阪梅田の南（135.49848, 34.701802） |
| 曲がる | 御堂筋と曽根崎通の交差点（135.500591, 34.698311） |

**ただし経路そのものは人が繋いだものです。**最短経路でも、歩行者に許された道でもありません。
**経路の計算は MMJ の仕事ではない**（D-003 / D-022）ので、ここにあるのは
「外から渡されたもの」の見本です。実際の案内に使うなら、
ルーティング API か AI が作ったものを同じ形で渡してください。

| 種類 | 役割 |
| --- | --- |
| `LineString` | 経路の線 |
| `Point` ＋ `instruction` | 曲がる地点の吹き出し（「コンビニを左折」） |
| `Point` ＋ `instruction` ＋ `image` | 写真つきの吹き出し |

**後から足せます。**案内の点だけ増やした GeoJSON を渡せば、そのぶんだけ吹き出しが増えます。
AI に経路と案内文を作らせて、この形で渡す使い方を想定しています。

## `sample-corner.svg`

**写真ではありません。**吹き出しに画像が載ることを見せるための見本です。
実在の交差点の写真を置くと、**いつか誰かがそれを本物として使います**。
