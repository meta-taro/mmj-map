# デモ用のデータ

## `sample-points.geojson`（200 点）

`<mmj-cluster>` が点をまとめる様子を確かめるためのデータです。

**実在の施設・店舗・イベントではありません。**梅田 / 難波 / 大阪城 / 堺 の 4 か所を
中心に、seed を固定した疑似乱数で散らしただけの合成点です。

実在のデータに見えるものを作り置くと、**いつか誰かがそれを本物として使います**。
`properties.name` を「サンプル点 N」にしてあるのはそのためです。

生成に使った値は次の通りで、同じ手順から同じファイルが出ます。

| 中心 | 経度 / 緯度 | 点数 | 散らす幅（度） |
|---|---|---|---|
| 梅田 | 135.4959 / 34.7024 | 70 | ±0.012 |
| 難波 | 135.5022 / 34.6659 | 60 | ±0.010 |
| 大阪城 | 135.5258 / 34.6873 | 40 | ±0.008 |
| 堺 | 135.4830 / 34.5733 | 30 | ±0.020 |

- 乱数は線形合同法（`s = (s * 1103515245 + 12345) % 2147483648`）、seed は `20260917`
- 緯度側だけ幅を 0.8 倍している（この緯度では経度 1 度のほうが短く、
  等倍にすると縦長の固まりに見えるため）
- 座標は小数 5 桁（約 1m）で丸めている

## `own-poi.geojson`（8 点）

`<mmj-poi>` が**利用者の持ち込みデータ**を重ねる様子を確かめるためのものです。

**実在の店舗ではありません。**京セラドーム周辺（135.4761 / 34.6693）に、
seed `20260917002` の同じ線形合同法で 8 点散らしただけの合成点です。

**名前は `name` ではなく `shop_name` に入れてあります。**
媒体ごとに属性名が違うこと（`label-key` で指定できること）を、
デモ側でも実際に使って示すためです。
