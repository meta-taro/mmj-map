## 0.3.0（2026-10-07）

### 時間で動くラスタ（`<mmj-raster frames=…>`）

```html
<mmj-raster src="./rain/{t}/{z}/{x}/{y}.png"
            frames="09:00,10:00,11:00" interval="650" autoplay></mmj-raster>
```

`src` の `{t}` が時刻の番号に置き換わります。見出しは置く側が書きます——
「10 分後」なのか「10/7 10 時」なのかは、置く側しか知りません。

時刻ぶんをまとめて置き、見せ方だけを切り替えます。毎回 source を作り直すと、
切り替えのたびに取りに行って白く抜けます。

| 足したもの | |
| --- | --- |
| `frames` | 時刻の見出しを読点区切りで |
| `interval` | 送りの間隔（ミリ秒）。既定 700 |
| `autoplay` | 置いただけで動き出す |
| `showFrame(n)` / `play()` / `pause()` | 頁側からの操作 |
| `mmj-raster-frame` | 送られたときに飛ぶ（`detail.index` / `detail.label`） |
| `mmj-raster-ready` | 用意ができたときに飛ぶ（`detail.frames`） |

実物: <https://meta-taro.github.io/mmj-map/rain.html>

### 台風（`<mmj-typhoon>`）

```html
<mmj-typhoon src="./data/typhoon.json"></mmj-typhoon>
```

強風域（黄）・暴風域（赤）・予報円（白の破線）・進路線（実績は実線／予報は破線）・中心。
報道で見る形に合わせてあります。

色は作っていません。黄と赤は気象庁の配色を写したものです。
**予報円は塗りません**——あれは中心の位置の不確かさで、暴風域とは別物です。
塗ると「この範囲が暴風」と読まれます。

**予報はしません**。渡された点を描くだけで、外挿も補間もしません。

### 挙動が変わるところ

**`<mmj-raster>` の `min-zoom` / `max-zoom` を、layer ではなく source に書くようにしました。**

タイルの有無は source の話です。layer に書くと「その範囲の外では描かない」に
なるだけで、

- 持っていない倍率のタイルを**取りに行き続けます**（z8 だけ置いた頁で 404 が 188 件）
- `min-zoom` を下回る倍率で開くと、**1 滴も描かれません**（タイルはあるのに真っ新）

既に `min-zoom` / `max-zoom` を「表示する倍率の範囲」として使っていた場合、
意味が変わります。**持っている倍率**を書いてください。

### 上げる前に読むところ

**MapLibre 6 に対応しました。5 系のままでも動きます。**
`peerDependencies` は `maplibre-gl: ">=5"` のままで、部品が見ているのは
`window.maplibregl` だけです。ここは変えていません。

ただし **MapLibre 6 は ESM だけを配っており、`dist/maplibre-gl.js`（UMD）がありません**。
6 系を使うなら、読み込み方がこう変わります。

```html
<!-- 5 系 -->
<script src="https://cdn.jsdelivr.net/npm/maplibre-gl@5.24.0/dist/maplibre-gl.js"></script>

<!-- 6 系 -->
<script type="module">
  import * as maplibregl from "https://cdn.jsdelivr.net/npm/maplibre-gl@6.12.0/dist/maplibre-gl.mjs";
  window.maplibregl = maplibregl;
</script>
```

版の数字だけ 6 に書き換えると **404 になり、地図が 1 枚も出ません**。
`import maplibregl from`（既定の輸入）も `undefined` になります（6 系に既定の輸出が無いため）。
`import * as` で受けてください。

6 系は **WebGL2 必須**です。自分で配信する場合、`.mjs` が JavaScript の
content-type で返ることも確かめてください（`application/octet-stream` で返すと、
HTTP 200 のままブラウザが実行を拒み、**地図だけが出ません**）。

### 店舗カード（`mmj-poi`）

点を押すと開くカードが、1 枚の吹き出しから**中身のある画面**になりました。

- 写真（複数あるときは横に流れる帯）・星・長文・ラベル付きリンク
- タブ（品書き・クーポン・営業時間など、任意の数）
- 開いたまま隣の店へ送る。開いている店は `?shop=` に残る（共有できる）
- 営業時間を曜日ごとに。口コミ本文
- `card-live` — 時間で変わる中身は、**開いたときに取りに行く**
- `card-rich` — 項目を名指ししたときだけ、本文を HTML として読む（既定は文字のまま）
- 地図と並ぶ一覧。探せる・検索エンジンに出る・キーボードで届く

### 地図まわり

- **点を自前の SVG アイコンにできる**
- **現在地**（`locate`）。通信が無くても出る
- **地図の時点を地図の中に出す**。配っているタイルがいつのものか
- **建物を、走っている地図でも立てたり寝かせたりできる**
- 地図の部品（帰属表示・縮尺・操作ボタン）も、読み込んだ配色に合わせる
- スマホでは下から出る面、PC では横から出る面。つまんで動かせる。全画面ボタン

### 直したもの

- **グリフをスタイルの位置から解く**。公開先が `/<repo>/` の下にあると
  `../glyphs/` が 1 つ上を指し、**本番だけで 404** になっていた。
  地図は出てラテン文字だけが閲覧側のフォントに化けるので、画面では気づけない
- 地図を押してカードを閉じたとき、点が元に戻らなかった
- 面が地図に沈み、吹き出しが真っ黒になっていた
- 矢印で送ったとき「いまここ」が分からなかった
