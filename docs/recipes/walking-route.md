# 駅から歩く経路を、手元で前もって作る

MMJ は経路を**計算しません**（[`docs/decisions.md`](../decisions.md) の D-003・D-036）。
この文書は、**経路の線を自分で用意して `<mmj-route>` に渡す**ための手順です。
MMJ の製品には入っていません。道具は使う側で選びます。

## 何を渡せばよいか

**線 1 本だけで足ります**。曲がり角の案内・目印・名札・分数は、MMJ が線から出します。

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "from": "A2 出口", "to": "ホテル月" },
      "geometry": {
        "type": "LineString",
        "coordinates": [[135.4985, 34.7018], [135.5006, 34.6983], [135.5055, 34.6980]]
      }
    }
  ]
}
```

| 欄 | 中身 |
| --- | --- |
| `coordinates` | 歩く順の `[経度, 緯度]`。**出発が先頭、到着が最後** |
| `from` | 出発の名札（駅の出口の名前など）。無ければ「出発」 |
| `to` | 到着の名札（店の名前など）。無ければ「到着」 |

```html
<mmj-route src="./routes/shop-123.geojson" fit steps landmarks ends summary></mmj-route>
```

特に言いたい角があれば、`instruction` を持つ点を足します。**書いた案内のそばには、自動の案内を重ねません。**

## なぜ「前もって」なのか

- **頁を開くたびに経路の API を呼ぶと、費用が閲覧数に比例します**。店と駅の組み合わせは決まっているので、1 回作れば使い回せます
- 作った線は**静的なファイル**です。MMJ の地図と同じく、静的配信だけで出せます

## 線の作り方

どの道具でも、**出力を上の形の GeoJSON にする**だけです。

1. **歩ける道のデータを用意する**
   OpenStreetMap の地域の抜き出し（例：Geofabrik の都道府県・地方ごとのファイル）を使います。
   使ったら、地図に `© OpenStreetMap contributors` を出します（ODbL）。MMJ の地図は最初から出しています
2. **出発点を決める**
   駅の出口が OSM にあれば（`railway=subway_entrance`）、そこから引きます。
   無い駅は駅の代表点から引き、名札は駅の名前にします（「A2 出口」と書かない）
3. **経路を求める**
   オープンソースの経路エンジン（OSRM・Valhalla・GraphHopper など。いずれも徒歩の設定がある）を手元で動かすか、
   道路を辺にしたグラフを自分で組んで最短経路を求めます。**サーバーとして公開する必要はありません**。手元で 1 回走らせるだけです
4. **GeoJSON に書き出す**
   座標の並びを `LineString` にし、`from` / `to` を付けて、店ごとに 1 ファイル（または 1 つにまとめて店の ID で引く）で置きます

## 作ったあとに確かめること

- **分数が、同じ頁の「駅から徒歩◯分」と合っているか**。MMJ は 1 分 80m・端数切り上げで出します。
  別の速さで書いている頁なら `walk-speed` を合わせます
- **数店を地図で見比べる**。線が建物や線路を突っ切っていないか、歩道橋や地下通路を通っていないか
- `mmj-route-ready` の `detail.steps` と `detail.landmarks` を画面に出して、**0 件の店が無いか**を見ます

分数だけを前もって計算したいときは、MMJ の関数をそのまま使えます。

```js
import { walkSummary, formatWalk } from "@mmj-map/elements/walk";
formatWalk(walkSummary(geojson)); // "徒歩 5 分・400m"
```
