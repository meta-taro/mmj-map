手元を見られない人へ渡すための実物です。**人が見て判断するための材料であって、
判断そのものではありません**（ベースルール §29）。

撮り方（依存は足していません。機械に入っているブラウザを CDP で動かしています）:

```bash
pnpm serve
```

## サイトの色を当てる — `2026-09-21-brand-accent.jpg`（2026-09-21）

`apps/demo/brand.html`。`accent` に 1 色渡すだけで、高速道路・駅の丸・目印の色が変わります
（D-020）。**土台は 6 枚から選び、色はこちらで作りません。**

![サイトの色を当てる](2026-09-21-brand-accent.jpg)

**撮って初めて分かった不具合 2 件**（どちらもテストは全部通っていました）

1. **ポップアップだけ暗い箱のままでした。**明るい土台に変えても変わらない。
   `<mmj-map>` が描画時に `replaceChildren` で子を DOM から外すため、
   子要素があとから `closest("mmj-map")` を呼ぶと **null** になり、親の配色を借りられていませんでした。
2. **テーマカラーを渡していない地図で、梅田の目印が灰色になりました。**
   「スタイルが元から持っている高速道路の色」を accent と同じ名前で扱ったせいで、
   `modern-dark` の `#4E5863` が目印へ流れていました。

**土台が 6 枚しかない**点は、人からの指摘として残っています（2026-09-21）。
