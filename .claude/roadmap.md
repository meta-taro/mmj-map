---

## S1 — 切り出して、先行実装の外で動かす

**このスプリントの完了条件は 1 つ。「先行実装を一切参照せずに、地図が 1 枚出ること」。**

- [ ] pnpm workspace としてリポジトリの骨格を作る
- [ ] 先行実装から次を取り出し、**そのサイト固有の語を外す**
  - [ ] 手書きダークスタイル（JSON）
  - [ ] タイル配信の経路（HTTP Range 206 を返す部分）
  - [ ] グリフ取得
- [ ] **タイル生成ワークフローは書き直す。** 先行実装のローカル生成スクリプトには
      特定の PC のパス前提が残っており、**再現可能ビルドの条件を満たしません**。
      公開データと公開ツールだけで完結する形に作り直します
- [ ] `apps/demo/` で**素の地図が 1 枚**出ることを確認する
- [ ] 帰属表示（`© OpenStreetMap contributors`）が画面に出ていることを確認する

### 切り出さないもの

- **先行実装の地図コンポーネント本体。** そのサイトの業態別 UI と不可分に混ざっており、
  **単純コピーになりません。**必要な骨だけを S2 で書き直します。

## S2 — UI 部品を Web Components にする

- [ ] Marker / Popup / Cluster を Web Components として書く
- [ ] 永続レイアウト（地図の状態を保ったまま周りだけ差し替わる形）
- [ ] **素の MapLibre を呼ぶのと変わらない厚さなら、そこで止める**（PRD §3）

## S3 — スタイルを作品として仕上げる

- [ ] Modern Dark を正式なテーマ 1 枚目にする
- [ ] ライトテーマ
- [ ] **鉄道の路線色は、事業者が決めている色をそのまま写す。**
      独自配色に置き換えない（読む人が混乱します）
- [ ] 日本語のラベル配置（地名の密度・漢字かな英数の混在）

## S4 — 公開して、使えるようにする

- [ ] npm パッケージとして配る
- [ ] ベースタイルの入手手順（自分でビルドする道を必ず残す）
- [ ] React / Vue ラッパ
- [ ] ドキュメントサイト

---

## 進め方の約束

- **S1 が終わるまで、S2 以降に手を出さない。**切り出しが終わらないうちに
  新機能を書くと、切り出し元と新規実装が混ざって、どちらも終わらなくなります。
- **各スプリントの完了条件は「動くものが 1 つ出ること」。**
  ドキュメントが揃ったことを完了にしない。
